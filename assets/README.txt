
ใส่รูปของคุณไว้ในโฟลเดอร์นี้

จำเป็น:
logo.png = โลโก้ที่จะใช้ทั้งหน้าแรกและหัวเว็บ

รูปเมนู:
1.png = ไอคอนเมนูประกันสังคม
2.png = ไอคอนเมนูครอบครัว
3.png = ไอคอนเมนูรักษาพยาบาล
4.png = ไอคอนเมนูเงินช่วยเหลือ/เงินกู้
5.png = ไอคอนเมนูกองทุนสำรองเลี้ยงชีพ
6.png = ไอคอนเมนูการแต่งกาย
7.png = ไอคอนเมนูการจ่ายค่าจ้าง
8.png = ไอคอนเมนูวันเวลาทำงาน/OT
9.png = ไอคอนเมนูวันลา

รูปประกอบในแต่ละหน้าสามารถตั้งชื่อเองได้ แล้วแก้ src ในหน้า HTML ที่เกี่ยวข้อง

ทุกจุดที่ต้องใส่รูปจากภาพต้นฉบับถูกเว้นเป็น placeholder แล้ว
ไม่มี emoji เป็นรูปเมนู และไม่มีปฏิทิน
